## 📖 Descripción

Este es el **Ejercicio 3** de mi serie de práctica en Java. El programa almacena
dos números enteros, calcula su **suma** con el operador `+` y muestra los
operandos junto con el resultado en consola.

> 🎯 **Objetivo del ejercicio:** usar el operador aritmético `+`, guardar el
> resultado en una variable y mostrar tanto los datos de entrada como la salida.

## ✨ Qué hace

```java
int numero1  = 15;
int numero2  = 7;
int resultado = numero1 + numero2;
```

Imprime:

```
Numero 1 = 15
Numero 2 = 7
la suma es = 22
```

## 🧠 Conceptos practicados

| Concepto | Descripción |
|:--|:--|
| Operador `+` | Suma de dos enteros |
| Variable de resultado | Guardar el cálculo en una `int` |
| Salida con concatenación | Mostrar entrada y resultado en pantalla |

## 🛠️ Requisitos

- **JDK 8** o superior ([Descargar JDK](https://adoptium.net/))
- Un editor: IntelliJ IDEA, VS Code o similar
- Terminal o símbolo del sistema

## ▶️ Cómo ejecutarlo

```bash
# 1. Compilar
javac src/Main.java

# 2. Ejecutar
java -cp src Main
```

O directamente desde **IntelliJ IDEA** → botón ▶ *Run*.
